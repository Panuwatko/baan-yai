# ทางกลับบ้านยาย

เกมผจญภัยแบบเลือกทางเดิน (text adventure) บนเว็บ มีธีมขับรถกลางคืนไปบ้านยาย ระหว่างทางคุณต้องตัดสินใจทุกครั้งที่ถนนแยกออก และแต่ละทางเลือกจะพาไปสู่ตอนจบที่ต่างกัน

ทำด้วย HTML, CSS และ JavaScript ล้วน ไม่มี framework และรองรับการติดตั้งเป็นแอปบนมือถือ (PWA) เล่นได้แม้ไม่มีอินเทอร์เน็ตหลังโหลดครั้งแรก

## ไฟล์สำคัญ

| ไฟล์ | หน้าที่ |
| --- | --- |
| `index.html` | หน้าหลักของเกม |
| `css/style.css` | สไตล์ทั้งหมด |
| `js/` | โค้ดเครื่องยนต์เกม เสียง และการบันทึก |
| `data/events.js` | เหตุการณ์และตัวเลือกระหว่างทาง |
| `data/endings.js` | ตอนจบ |
| `sw.js` | service worker สำหรับเล่นออฟไลน์ |
| `manifest.webmanifest` | ข้อมูลสำหรับติดตั้งเป็นแอป |

## รันบนเครื่องตัวเอง

ES modules และ service worker ต้องรันผ่าน `http://` ไม่ใช่เปิดไฟล์ตรงๆ (`file://`) จึงต้องเริ่มเซิร์ฟเวอร์เล็กๆ ก่อน

```bash
cd baan-yai
python3 -m http.server 8123
```

จากนั้นเปิด http://localhost:8123 ในเบราว์เซอร์

## นำขึ้นออนไลน์ฟรี

### GitHub Pages

1. สร้าง repository ใหม่บน GitHub (เช่น `baan-yai`)
2. push โค้ดขึ้น branch `main`
3. ไปที่ **Settings → Pages**
4. ที่ **Build and deployment** เลือก **Deploy from a branch**, branch `main`, folder `/ (root)` แล้วกด Save
5. รอสักครู่ เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/baan-yai/`

### Vercel หรือ Netlify

ลากโฟลเดอร์ `baan-yai` ไปวางในหน้า dashboard ของ Vercel หรือ Netlify ก็ได้เว็บทันที ไม่ต้องตั้งค่าอะไรเพิ่ม

## ติดตั้งลงมือถือ

- **Android (Chrome):** เปิดเว็บ กดเมนู ⋮ แล้วเลือก **"เพิ่มลงในหน้าจอหลัก"**
- **iPhone (Safari):** เปิดเว็บ กดปุ่มแชร์ แล้วเลือก **"เพิ่มไปยังหน้าจอโฮม"**

## เพิ่มเหตุการณ์ใหม่

แก้ไฟล์ `data/events.js` โดยดูคำอธิบายรูปแบบข้อมูล (schema) ที่คอมเมนต์อยู่ด้านบนสุดของไฟล์นั้น เพิ่มเหตุการณ์หรือตัวเลือกตามรูปแบบเดิม แล้วทดสอบบนเครื่องก่อนนำขึ้นออนไลน์

## อย่าลืมเมื่อ deploy ทุกครั้ง

ให้เปลี่ยนค่า `CACHE` ใน `sw.js` ทุกครั้งที่ deploy เช่นจาก `"baanyai-v1"` เป็น `"baanyai-v2"` เพราะมือถือที่ติดตั้งแอปไว้แล้วจะใช้ไฟล์ที่แคชไว้เดิม หากไม่เปลี่ยนค่านี้ ผู้เล่นอาจไม่เห็นการอัปเดต
